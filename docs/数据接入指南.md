# 数据接入指南：如何添加新公司 / 新数据

本系统估值一家公司需要 **5 类数据**（对应方案 4.1 的前五类数据源）。
本文说明每类数据长什么样、从哪里获取、怎样导入。

## 一、系统需要什么数据（数据集的样子）

| 数据集 | 文件 | 关键字段 | 单位 | 必需性 |
|---|---|---|---|---|
| 公司主数据 | `companies.csv` | company_id、名称、行业代码、市场、代码、报告/交易币种、beta | — | **必需** |
| 年度财务报表 | `financials.csv` | 财年、期末日、**披露日**、~40 个统一科目（利润表/资产负债表/现金流量表） | 报告币种**百万** | **必需（≥2 年，建议 5-6 年）** |
| 股本 | `share_counts.csv` | 时点、总股本、稀释加权股本 | **百万股** | **必需** |
| 收盘价 | `prices.csv` | 日期、收盘价（月度即可，越多历史分位越准） | 交易币种 | **必需** |
| 每股分红 | `dividends.csv` | 财年、DPS | 报告币种 | 可选 |
| 可比公司 | `peers.csv` | 对象公司、入选理由 | — | 可选（缺省时相对估值退化为只用自身历史分位） |

模板都在 `backend/app/seed/templates/` 里，打开照着填即可。三点提醒：

1. **金额一律为"报告币种的百万"**：如茅台营收 1741 亿 → 填 `174144`；苹果营收 3910 亿美元 → 填 `391035`。
2. **披露日（published_at）必须填真实的年报发布日**，不是财年结束日——系统的时点引擎靠它防止"未来数据泄漏"（方案 2.4）。
3. 行业代码可选：`consumer / manufacturing / software / internet / utilities / bank / insurance`（银行保险目前仅相对估值）。

财务科目最少填这些就能跑通估值（其余科目缺省会降低"数据完整性"得分但不阻断）：
`revenue, cost_of_revenue, operating_profit, pre_tax_income, income_tax, net_income,
net_income_attributable_parent, cash_and_equivalents, short_term_debt, long_term_debt,
total_assets, total_liabilities, shareholders_equity, cash_flow_from_operations,
capital_expenditure, depreciation_amortization`

## 二、怎么导入

把填好的 CSV 放进一个文件夹（如 `mydata/`），执行：

```bash
cd backend
python -m app.seed.csv_import --dir mydata
```

导入是**幂等**的（重复导入按主键覆盖），完成后自动执行勾稽与异常检查（方案 15）。
之后在前端搜索新公司 → 点"运行估值"即可。年报更正/重述用 `revision_version=2` 再导一行。

## 三、从哪里直接拿数据

### 美股：一条命令自动抓取（推荐先用这个）✅

美股有官方免费的结构化接口（SEC EDGAR XBRL），系统已内置适配器，**不用手工填 CSV**：

```bash
cd backend
python -m app.seed.fetch_us NVDA --company-id nvda --industry manufacturing --name-zh 英伟达 --contact 你的邮箱
python -m app.seed.fetch_us PG   --company-id pg   --industry consumer      --name-zh 宝洁
```

自动完成：SEC 查 CIK → 拉 Company Facts（年报财务+稀释股本+DPS，自动吸收 10-K/A 更正）
→ stooq 拉月度收盘价 → 入库 → 质量检查。数据质量等级 B（官方结构化数据）。
注意：SEC 要求自动化访问声明联系方式（`--contact`），频率限制每秒 10 次以内（系统仅 3 次请求）。

### A股：免费数据源 + CSV（或等下一阶段适配器）

| 来源 | 内容 | 形式 | 说明 |
|---|---|---|---|
| [巨潮资讯网](http://www.cninfo.com.cn) | 年报/公告 PDF、XBRL | 网页/接口 | **官方披露源**，年报数字以此为准 |
| 上交所/深交所官网 | 定期报告、行情 | 网页 | 官方 |
| [AKShare](https://akshare.akfamily.xyz)（Python 库，免费） | 三大报表、行情、股本、分红 | DataFrame | `pip install akshare`，聚合自东财/新浪等，**最适合程序化获取** |
| [baostock](http://baostock.com)（免费） | 行情、部分财务指标 | Python | 稳定但科目较少 |
| [Tushare](https://tushare.pro)（注册积分制） | 全套财务+行情 | Python | 积分够时最全 |
| 东方财富/同花顺 F10 页面 | 财务摘要 | 网页 | 手工抄录到 CSV 也够用（一家公司 6 年约 20 分钟） |

AKShare 取数示例（在您本机运行，把结果对照模板整理成 CSV）：

```python
import akshare as ak
# 利润表/资产负债表/现金流量表（新浪财经接口，单位：元 → 记得换算成百万）
income = ak.stock_financial_report_sina(stock="sh600519", symbol="利润表")
balance = ak.stock_financial_report_sina(stock="sh600519", symbol="资产负债表")
cash = ak.stock_financial_report_sina(stock="sh600519", symbol="现金流量表")
# 月度收盘价（前复权不要用！系统要原始收盘价 → adjust=""）
px = ak.stock_zh_a_hist(symbol="600519", period="monthly", adjust="")
```

### 港股：免费数据源 + CSV

| 来源 | 内容 | 说明 |
|---|---|---|
| [HKEXnews 披露易](https://www.hkexnews.hk) | 年报/业绩公告 PDF | **官方披露源**，多为 PDF，需手工摘录关键科目 |
| AKShare | 港股行情、部分财务 | `ak.stock_hk_hist(symbol="00700", period="monthly", adjust="")` |
| stooq.com | 港股月度价格 CSV | `https://stooq.com/q/d/l/?s=0700.hk&i=m` 直接下载 |

港股公司注意：腾讯/小米等**报告币种是人民币、交易币种是港币**，companies.csv 里
`report_currency=CNY, trading_currency=HKD`，系统会自动做汇率换算。

## 四、"拿下来的数据能不能直接处理？"——如实回答

| 数据形式 | 能否直接处理 | 说明 |
|---|---|---|
| **本系统 CSV 模板** | ✅ 直接导入 | `csv_import --dir` 一条命令 |
| **SEC EDGAR（美股）** | ✅ 已内置适配器 | `fetch_us` 一条命令全自动 |
| AKShare/Tushare 的 DataFrame | ⚠️ 需要一次转换 | 科目名是中文原始名（"营业总收入"），需按映射表整理成统一科目 CSV；这正是方案 5.2"科目映射"的工作 |
| 交易所/巨潮的 PDF 年报 | ❌ 不能直接 | 需人工摘录或等阶段 2 的解析管道 |
| 复权后的行情数据 | ❌ 不要导入 | 系统只存**原始收盘价**（方案 4.1），分红送股另行记录 |

换句话说：**美股已经全自动；A股/港股目前"半自动"**——用 AKShare 等免费源取数，
按模板整理成 CSV（一次性写个小脚本即可），导入后系统的标准化、质量检查、估值全流程都能直接处理。
A股的 AKShare 自动适配器是路线图下一项（需要在能访问东财接口的网络环境开发验证），需要的话告诉我，我按 `fetch_us` 同样的模式补一个 `fetch_cn`。

## 五、许可合规提醒（方案第二十一章）

- 公司**披露文件**（年报、公告）本身可自由使用；
- **行情数据**的展示、再分发、商用受交易所和数据商许可约束，免费源（AKShare/stooq/雅虎）适合个人研究，商用请购买合规行情；
- SEC 接口请遵守 User-Agent 声明与频率限制。
